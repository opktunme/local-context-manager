# Security policy

## Supported versions

Security fixes are applied to the latest release and the default branch.

## Reporting a vulnerability

Please use GitHub's private **Report a vulnerability** flow in the repository Security tab. Do not include exploit details, private prompts, credentials, or local database contents in a public issue.

If private vulnerability reporting is unavailable, open a minimal public issue asking a maintainer to establish a private contact channel, without disclosing sensitive details.

LCM is intended for trusted local networks. It is not an authentication gateway and should not be exposed directly to the public internet.
